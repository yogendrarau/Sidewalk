## Opt-in live rehearsal prerequisites

The live test is skipped unless the prepared fictional Shopify store is configured with `SHOPIFY_STORE_DOMAIN`, `SHOPIFY_ADMIN_ACCESS_TOKEN`, `SHOPIFY_STOREFRONT_ACCESS_TOKEN`, `SHOPIFY_API_VERSION=2026-07`, and `SHOPIFY_PUBLICATION_ID`. It must use only named fictional test products. OAuth, webhooks, protected-customer-data order access, real payment, payout, and NYC verification are not accepted as implemented without separate exercised evidence.
